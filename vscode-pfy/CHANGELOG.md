# Changelog

## 1.0.1

- Detect Pfy 1.0 files from their header when they do not have a `.pfy` extension.
- Added a lowercase `pfy` language alias.

## 1.0.0

- Initial language support for Pfy 1.0.
- Added TextMate grammar, language configuration, and snippets.
- Added optional file icon theme for `.pfy` and `.pfyb`.
- Added the Playfy backup document snippet.
